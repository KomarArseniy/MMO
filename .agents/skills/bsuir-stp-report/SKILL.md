# Генератор отчетов по лабораторным работам (СТП БГУИР 01-2017 / 01-2024)

Данный скил предназначен для быстрой, автоматизированной генерации отчетов по лабораторным работам на LaTeX в строгом соответствии со стандартом предприятия БГУИР (СТП 01-2017 / СТП 01-2024) и обязательной 7-элементной структурой.

---

## 1. Обязательная структура отчета (7 разделов)

Каждый отчет обязан строго содержать следующие 7 разделов:
1. **Титульный лист**:
   - Включается в общую нумерацию (стр. 1), но номер страницы **не печатается**.
   - **ОБЯЗАТЕЛЬНО** указать **номер варианта** (например: «Вариант № 14»).
   - Указываются: Министерство, БГУИР, факультет, кафедра, номер и тема лабораторной, ФИО студента, группа, преподаватель, Минск и год.
2. **Цель выполнения лабораторной работы** (`\section{Цель работы}`).
3. **Теория по лабораторной работе** (`\section{Краткие теоретические сведения}`):
   - **СТРОГО НЕ БОЛЕЕ 4 СТРАНИЦ** (контролируется скриптом валидации).
4. **Формулировка индивидуального задания** (`\section{Формулировка индивидуального задания}`).
5. **Весь код решения индивидуального задания** (`\section{Код решения индивидуального задания}`):
   - Исходный код оформляется шрифтом **Courier New 13 pt**, одинарный межстрочный интервал (1.0), абзацный отступ 0.
   - **СТРОГО БЕЗ РАМКИ И БЕЗ ФОНОВОЙ ЗАЛИВКИ** (border: none, background: transparent).
6. **Скриншоты выполнения индивидуального задания** (`\section{Результаты выполнения индивидуального задания}`):
   - Скриншоты работы программы с подписями по СТП (`Рисунок X – Подпись` по центру, без точки на конце).
   - Обязательные ссылки из текста на каждый рисунок («на рисунке 1...»).
7. **Выводы по лабораторной работе** (`\section{Выводы}`).

## 2. Параметры оформления по стандарту СТП БГУИР

- **Формат листа**: A4 (297 × 210 мм).
- **Поля**:
  - Левое: **30 мм** (3 см).
  - Правое: **15 мм** (1,5 см).
  - Верхнее: **20 мм** (2 см).
  - Нижнее: **20 мм** (2 см).
- **Шрифт основного текста**: Times New Roman, **14 пунктов** (`\documentclass[14pt,a4paper]{extarticle}`).
- **Шрифт кода**: Courier New, **13 пунктов**, интервал 1.0, без рамок.
- **Межстрочный интервал**: **1,0** (одинарный, 18 pt).
- **Абзацный отступ**: строго **1,25 см** (5 знаков).
- **Выравнивание текста**: по ширине страницы (`\sloppy`).
- **Нумерация страниц**: арабскими цифрами в **правом нижнем углу**, 10 мм от нижнего края листа, 15 мм от правого края (`\fancyfoot[R]{\thepage}`). Со 2-й страницы.
- **Заголовки**:
  - Нумерованные разделы: `1 ЦЕЛЬ РАБОТЫ` (прописные, полужирный, 14pt, выравнивание по левому краю с отступа 1.25 см, без точки в конце, пустая строка после заголовка, **каждый раздел первого уровня строго с новой страницы**).
  - Подразделы: `1.1 Подраздел` (строчные, полужирный, 14pt, отступ 1.25 см, без точки).
  - Ненумерованные разделы: по центру, прописные, без абзацного отступа.
- **Подписи рисунков**: `Рисунок 1 – Результат работы` (по центру, тире, без точки).
- **Подписи таблиц**: `Таблица 1 – Данные` (над таблицей, по левому краю без отступа, тире, без точки).
- **Формулы**: по центру, векторный рендеринг MathML / STIX, номер справа `(1)`, расшифровка со слова «где» с новой строки без отступа и без двоеточия.

## 3. Быстрый запуск и автоматизация (Кушает минимум времени)

Для работы используется готовый Python-генератор:
`scripts/generate_report.py`

### Способ А: Авто-обнаружение по папке (Самый быстрый!)
Если в папке (например, `tasks/lab1` или `labs/lab1`) уже лежат файлы задания (`task.md`), исходный код (`*.py`, `*.cpp`) или скриншоты:
```powershell
python <path_to_skill>/scripts/generate_report.py --auto ./tasks/lab1 --variant 12 --lab 1 -s "ОАиП" --student "Иванов И. И." --group "150501" -o ./results/lab1
```
Скрипт автоматически:
1. Найдет код и подключит через `\lstinputlisting` с правильным языком.
2. Найдет скриншоты, скопирует в `images/` и создаст блоки рисунков с подписями и текстовыми ссылками.
3. Проверит объем теории (предупредит, если превышает 4 страницы).
4. Создаст готовый `main.tex`, скопирует `bsuir_stp.sty`.
5. Упакует все в архив `report_lab1_var12.zip` для Overleaf.
6. Скомпилирует PDF, если в системе установлен компилятор.

### Способ Б: Через YAML/JSON конфигурацию
1. Сгенерировать шаблон конфига:
```powershell
python <path_to_skill>/scripts/generate_report.py --init ./lab_config.yaml
```
2. Заполнить нужные поля и выполнить сборку:
```powershell
python <path_to_skill>/scripts/generate_report.py -c ./lab_config.yaml -o ./results/lab1
```

## 4. Проверка и валидация отчета

Для проверки любого отчета `main.tex` на строгое соответствие 7 пунктам и СТП:
```powershell
python <path_to_skill>/scripts/validate_report.py ./results/lab1/main.tex
```
Валидатор автоматически проверит:
- Наличие титульного листа и обязательного номера варианта.
- Наличие всех 7 обязательных разделов.
- Лимит объема теории (<= 4 страниц).
- Форматирование подписей рисунков по СТП.
- Поля 30/15/20/20, шрифт 14pt, отступ 1.25 см, нумерацию страниц в правом нижнем углу.
