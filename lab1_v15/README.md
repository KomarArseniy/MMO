## 1. Теория: основные понятия

| Понятие | Что это |
|---|---|
| **Искусственный интеллект (ИИ)** | Самая широкая область: любые системы, которые решают задачи, требующие интеллекта. Включает и системы с ручными правилами |
| **Машинное обучение (ML)** | Часть ИИ. Алгоритм выводит правила из данных, а не получает их от программиста |
| **Глубокое обучение (DL)** | Часть ML. Глубокие нейронные сети, хороши для изображений, звука и текста, требуют много данных |
| **Data Science** | Работа с данными целиком: сбор, очистка, анализ, статистика, визуализация, модели, выводы. ML лишь один из её инструментов |
| **Data Mining** | Поиск скрытых закономерностей в больших данных |
| **Big Data** | Данные, которые не обрабатываются обычными средствами из-за объёма или скорости |

Вложенность: ИИ ⊃ ML ⊃ DL. Data Science пересекается со всеми, но это про процесс работы с данными.

### Ключевая идея ML

- Обычная программа: **данные + правила → ответ**.
- ML: **данные + правильные ответы → правила (модель)**.

### Словарь

- **Объект**: одна строка таблицы. **Признак (feature)**: один столбец. **Целевая переменная (target)**: то, что предсказываем.
- **Модель**: функция «признаки → предсказание». **Обучение**: подбор её параметров по данным.
- **Обучающая и тестовая выборки**: на первой учимся, на второй проверяем (например, 80% / 20%).
- **Функция потерь**: число, показывающее ошибку модели. **Метрика**: показатель качества на тесте (accuracy, MAE, F1).
- **Гиперпараметр**: настройка, которую задаёт человек до обучения.
- **Переобучение**: модель зазубрила обучающие данные и плохо работает на новых. **Недообучение**: модель слишком простая.

### Виды обучения

| Вид | Данные | Задачи | Пример |
|---|---|---|---|
| С учителем | признаки + ответы | классификация (категория), регрессия (число) | спам или нет; цена квартиры |
| Без учителя | только признаки | кластеризация, аномалии | группы покупателей |
| С подкреплением | награда и штраф от среды | игры, роботы | программа учится играть в шахматы |

### Этапы проекта

Сбор данных → очистка → анализ (EDA) → модель → оценка → внедрение и мониторинг.

## 4. Что делает каждый файл

**part1.py.** Меню выбора задания 1–6 (0 - выход):
1. секунды в формат `дни:часы:минуты:секунды`;
2. все числа из введённой строки;
3. гласные и согласные в словах списка `['Python', 15442, 32, 'QweRty', 34, 19, 'love']`;
4. слияние нескольких словарей;
5. меню «Ювелирный магазин» (описание, цена, количество, вся информация, покупка, выход);
6. сумма элементов кортежа до первого отрицательного.

**part2.py.** Без меню, выводит все результаты подряд:
1. `prime(n)` возвращает n-е простое число;
2. `universal(arg)` ведёт себя по-разному для списка, словаря, числа и строки;
3. первый столбец матрицы из отрицательных чисел и его среднее (в конце можно ввести свою матрицу);
4. демонстрация `try/except/else/finally`.

**part3.py.** Без меню, в задании 3 спрашивает размеры комнаты:
1. класс `List` с методами `add`, `insert_at`, `remove_value`, `reverse`, `unique`, `sort`, `max`, `sum`;
2. классы `Vehicle`, `Plane`, `Train`, `Car` с переопределением `way_of_moving`, поиск самой быстрой и самой дешёвой поездки, запись в `trips.txt`;
3. площадь стен для обоев без окон и дверей (пример: 5, 4, 2.5, окно 1.5×1.4, дверь 0.9×2.1 даёт 41.01 м²);
4. класс `BankAccount` с методами экземпляра, `@classmethod` и `@staticmethod`.
