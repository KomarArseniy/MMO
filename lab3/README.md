# ЛР3. Градиентный спуск (вариант 15, L2-регуляризация)

Запуск (из папки lab3):

    pip install -r requirements.txt
    python lab3_gd.py

Скрипт печатает результаты в консоль и сохраняет 3 графика в `figures/`:
1. `01_learning_rates.png` - влияние скорости обучения на GD;
2. `02_gd_vs_sgd.png` - MSE для GD и SGD на одном графике;
3. `03_l2_weights.png` - веса модели при 20 коэффициентах L2 (0.001 ... 1000).
