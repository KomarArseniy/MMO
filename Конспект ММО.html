Вложенность терминов

Data Science стоит немного сбоку: это вся работа с данными, от сбора до выводов. ML в ней один из инструментов.

Главная идея ML

В обычном программировании вы пишете правила сами: «если сумма больше 100, то скидка 5%». В ML вы даёте примеры, а правила программа находит сама.

ВходВыход
Обычная программаданные + правилаответ
Машинное обучениеданные + правильные ответыправила (модель)

Пример. Хотим определять спам. Вместо списка запрещённых слов даём 10 000 писем с пометкой «спам / не спам». Алгоритм выясняет, какие признаки чаще встречаются в спаме. Получившийся набор правил называется моделью.

Как выглядит проект целиком

Модель занимает лишь один шаг из шести. Чаще всего основное время уходит на очистку данных: убрать дубликаты, заполнить пропуски, привести всё к одному формату. Поэтому ЛР2 называется «Разведочный анализ данных».

Переменные и типы

Переменная это имя, которое указывает на значение. Тип определяется по значению.

Исключения: try / except / else / finally

Исключение это ошибка во время работы (деление на ноль, неверный ввод). Без обработки программа падает. С обработкой вы сами решаете, что делать дальше.

try:
    n = int(input("Число: "))
    print(10 / n)
except ValueError:              # ввели не число
    print("Нужно целое число")
except ZeroDivisionError:       # ввели 0
    print("Делить на ноль нельзя")
else:                           # исключения не было
    print("Всё прошло гладко")
finally:                        # выполнится в любом случае
    print("Конец блока")

В finally обычно закрывают файлы и соединения.

Классы и объекты

Класс это чертёж, объект это конкретная вещь по чертежу. Атрибуты хранят данные, методы описывают действия.

class Account:
    bank = "БелБанк"                 # атрибут класса, общий для всех

    def __init__(self, owner, balance=0):   # конструктор
        self.owner = owner                  # атрибуты экземпляра
        self.balance = balance

    def deposit(self, x):                   # метод экземпляра
        self.balance += x

    @classmethod
    def from_string(cls, s):                # метод класса: получает сам класс
        owner, bal = s.split(";")
        return cls(owner, float(bal))

    @staticmethod
    def is_valid(x):                        # статический: не знает ни self, ни cls
        return x > 0

acc = Account("Иван", 100)
acc.deposit(50)
Вид методаПервый параметрКогда нужен
Экземпляраselfработает с данными конкретного объекта
@classmethodclsальтернативные конструкторы, работа с атрибутами класса
@staticmethodнетвспомогательная функция, логически связанная с классом

Наследование и переопределение

class Vehicle:
    def way_of_moving(self):
        return "неизвестно"

class Plane(Vehicle):                # Plane наследует всё от Vehicle
    def way_of_moving(self):         # и переопределяет метод
        return "по воздуху"

Вызов way_of_moving() у объекта Plane выполнит версию из Plane. Это полиморфизм: один и тот же вызов, разное поведение.
